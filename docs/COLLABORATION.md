# 《战争进化史 3D》多线程敏捷协同开发工作流 (COLLABORATION.md)

为了实现类似于多线程的高效并发推进，本项目建立 **三位一体敏捷开发团队流水线**：

```
       ┌────────────────────────────────────────────────────────┐
       │             角色 1：用户 (总监 & 动效品质审核)           │
       │       • 视觉一票否决权   • 体验手感审核   • 动作节奏定板       │
       └─────────────────────────┬──────────────────────────────┘
                                 │ 验收反馈 & 决策批准
         ┌───────────────────────┴───────────────────────┐
         ▼                                               ▼
┌─────────────────────────────────┐   ┌─────────────────────────────────┐
│     角色 2：开发工程师 (Coder)    │   │    角色 3：策划与设计师 (Designer)│
│ • Three.js 场景与光影引擎构建      │   │ • 5 大时代数值平衡表 (攻防/克制)  │
│ • ECS 兵线状态机 & 碰撞索敌      │   │ • 战场 HUD & 战术底栏界面设计     │
│ • 投射物粒子 & Web Audio 音效   │   │ • 开源 3D 模型与动作资产检索清洗  │
└─────────────────────────────────┘   └─────────────────────────────────┘
```

---

## 一、三方职责详细分工表

### 👤 角色 1：用户（Director & Animation QA · 质检总监）
- **核心定位**：把控全局方向，对模型造型、骨骼姿态、动作流畅度与战斗爽快感进行审核把关。
- **输入物**：运行在浏览器中的实时预览页面（如 `walk_demo.html` 或后续的 `ModelInspector.html`）。
- **具体工作**：
  1. 在浏览器中切视角、测试各兵种的迈步、挥刀、举枪、受击动作；
  2. 评判动作是否自然（太快、太僵硬、还是打击感不够）；
  3. 决定某个模型是否采用，确认后下达放行指令。

---

### 💻 角色 2：开发工程师（Coder · 核心系统研发）
- **核心定位**：专注于代码层面的高健壮性、模块化与高性能执行。
- **技术栈**：原生 JavaScript (ESM) + Three.js + Web Audio API。
- **具体工作**：
  1. 按照 `docs/ARCHITECTURE.md` 搭建 3D 战场走廊与双方要塞；
  2. 实现基于 ECS 的轻量级出兵排队、寻敌距离计算与伤害结算；
  3. 封装骨骼动画控制器（AnimationDirector），实现动作平滑融合；
  4. 编写子弹/箭矢物理抛物线、粒子爆炸系统与合成音频。

---

### 🎨 角色 3：策划与设计师（Designer · 数值与视觉策划）
- **核心定位**：游戏玩法深度设计、时代克制数值表与 UI 视觉规划。
- **具体工作**：
  1. **数值矩阵设计**：制定 30 个兵种的《金币造价、攻击力、攻击距离、移速、血量、秒伤 DPS》数值平衡表，确保每个时代有轻型近战、远程火力、重型核心的相互克制；
  2. **UI 视觉规划**：设计时代演进天平条、底部造兵快捷栏冷却倒计时、伤害浮动飘字排版；
  3. **资产精选**：从 Quaternius / Kenney / Mixamo 筛选出最符合当前时代调性的新 3D 模型与贴图，交由工程师接入。

---

## 二、多线程并行开发的日常迭代流（3 步闭环）

1. **Step 1【设计与资产准备 (Designer)】**：
   - 设计师产出兵种配置表（`src/config/units.js`）及所需的 3D 模型资源链接；
2. **Step 2【系统开发与动作接入 (Coder)】**：
   - 工程师编写核心逻辑，将模型接入场景并做好动作触发器，启动本地服务更新；
3. **Step 3【实时检视与定板 (User)】**：
   - 用户在浏览器中打开页面进行动态检视，确认动作通过后，自动进入下一个时代的开发循环！
